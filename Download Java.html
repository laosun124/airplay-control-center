Install Java 21 or later

AirPlay Control Center requires Java, which is not included in the software ZIP.

Opening the official Eclipse Adoptium download page…

Download Eclipse Temurin Java 21 for Windows x64

Choose the Windows x64 installer (JRE or JDK). Enable Add to PATH during installation, then reopen AirPlay Control Center. Alternatively, set JAVA_HOME to the installed Java folder.

If Java cannot be found after installation, restart Windows so desktop apps receive the updated environment.
