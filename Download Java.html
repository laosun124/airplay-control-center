Install Java 21 or later

AirPlay Control Center requires Java, which is not included in the software ZIP.

Opening the official Oracle Java download page…

Download Java from Oracle

Choose a Windows x64 JDK installer for Java 21 or later (Java 25 is supported). Reopen AirPlay Control Center after installation. If Java is not detected, set JAVA_HOME to the installed JDK folder or add its bin directory to PATH.

If Java cannot be found after installation, restart Windows so desktop apps receive the updated environment.
